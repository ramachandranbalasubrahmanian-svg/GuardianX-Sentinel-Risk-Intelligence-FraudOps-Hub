# 🛡️ GuardianX Sentinel: Sovereign Risk Intelligence Hub

GuardianX Sentinel is an enterprise-grade **Fraud Operations (FraudOps)** platform designed to detect, analyze, and neutralize financial threats in real-time. It combines **Ensemble Machine Learning** with a high-density, **Sovereign Interface** for total transactional control.

## 🚀 The Layman's Pitch
Imagine a security guard that never sleeps, checking millions of transactions every second. While most software only follows simple lists of "bad things," **GuardianX** uses a brain of interconnected AI (powered by Google Gemini) to understand *context*. It knows if a purchase is a legitimate business trip or a stolen card, and it explains its "reasoning" to human experts so they can make the final call.

## 🌟 Key Capabilities
- **Intelligence Orchestration**: Integrated with **Google Gemini 1.5 Flash** to predict emerging threat vectors and suggest proactive mitigation rules.
- **Explainable AI (XAI)**: No more "black boxes." Sentinel provides a detailed logic trace for every flagged transaction, showing exactly *why* a score was assigned.
- **Sovereign Privacy Center**: A dedicated hub for GDPR/CCPA compliance, featuring automated PII masking and a "Sovereign Purge" engine for data-subject requests (DSR).
- **Agile Policy Sandbox**: Test new fraud-fighting logic against simulated data before deploying it to 12 global regions with zero downtime.

## 🏗️ Technical Architecture
- **Frontend Core**: React 18+ with Vite for sub-millisecond responsiveness.
- **AI Engine**: Google GenAI SDK for heuristic logic and rule generation.
- **Visualization**: D3.js and Recharts for high-fidelity transactional vector analysis.
- **Security Logic**: Multi-tiered **RBAC** (Role-Based) and **ABAC** (Attribute-Based) access control, ensuring that only certified admins can access sensitive PII or initialize data purges.

## 🔒 Security & Privacy
GuardianX Sentinel is built on a **Security-First** foundation:
- **Zero-Hardcode Policy**: All API keys and secrets are managed via enterprise-grade environment secrets.
- **Lazy SDK Instantiation**: AI capabilities are initialized only upon explicit user intent, minimizing the attack surface.
- **AES-256-GCM**: Industry-standard encryption for all data at rest and in transit.
